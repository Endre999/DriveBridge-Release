# DriveBridge – letöltés tesztelőknek

A DriveBridge Android-alkalmazás: vezetés közben, a telefon érintése nélkül beszélhetsz a saját Claude-fiókoddal. A kérdést diktálod, a választ az autó hangszórója olvassa fel, a vezérlés az autó médiagombjaival megy.

Az alkalmazás zárt tesztben van, és nincs a Google Playen.

## Jelenlegi állapot

A korábbi 0.9.0 verzió már nem működik, ezért eltávolítottuk. Jelenleg a **0.10.0 verzió tesztelése folyik**, ehhez innen még nincs nyilvános letöltés.

**Az aktuális állapotról kérdezz meg engem telefonon.**
